# DayTasks

Настольный канбан-планировщик на один компьютер: три колонки **Новые / В работе / Выполнено**.

## Возможности

- Три колонки; карточки перетаскиваются мышкой между колонками, колонки тянутся до краёв окна при любом размере.
- Важность задачи: Высокая (красный кружок) / Средняя (жёлтый) / Низкая (зелёный) — кружок справа сверху на карточке.
- Дедлайн в формате ДД.ММ.ГГГГ (кнопки «+1/+3/+7 дней»). Просроченная активная задача подсвечивается тускло-красным целиком и помечается «ПРОСРОЧЕНО».
- Удаление задачи: крестик на карточке или кнопка в диалоге (с подтверждением).
- Описание задачи, просмотр и редактирование в диалоге, перемещение кнопками.
- Сортировка карточек: переключатель вверху — **«Без сортировки»** (умный порядок: просрочка сверху, затем по дедлайну) и **«По наименованию»** (алфавитный порядок внутри каждой колонки).
- Темы: переключатель **«Тёмная / Светлая»** вверху справа. Выбор запоминается (файл `%APPDATA%\DayTasks\settings.json`) и восстанавливается при следующем запуске.
- Выделение карточек: одинарный клик выделяет карточку (синяя рамка), двойной клик открывает карточку для работы с ней (описание, важность, дедлайн), клик по пустому месту или Esc — снимает выделение.
- Иконка приложения: `assets\icon.png` / `assets\icon.ico` (в exe встроена при сборке).
- Данные хранятся в `%APPDATA%\DayTasks\tasks.json` (создаётся автоматически).

## Горячие клавиши

| Клавиши | Где | Действие |
|---|---|---|
| Ctrl+C / Ctrl+V / Ctrl+X | поля ввода | копировать / вставить / вырезать (работают на любой раскладке, включая русскую) |
| Ctrl+A | поля ввода | выделить весь текст |
| Ctrl+Z / Ctrl+Y | поля ввода | отменить / вернуть ввод |
| Ctrl+N | главное окно | новая задача |
| F5 | главное окно | перечитать задачи из файла |
| Delete | главное окно | удалить выделенную карточку (с подтверждением) |
| Esc | главное окно | снять выделение |
| Esc | окно задачи | закрыть без сохранения |
| Ctrl+Enter | окно задачи | сохранить задачу |
| Одинарный клик | карточка | выделить карточку |
| Двойной клик | карточка | открыть задачу (описание, важность, дедлайн) |

## Запуск из исходников

```bash
pip install -r requirements.txt
python daytasks.py            # обычный запуск
python daytasks.py --demo     # запуск с демо-задачами (данные во временном файле)
python daytasks.py --selftest # проверка логики без GUI
```

## Сборка exe

```bash
python -m PyInstaller --noconfirm --clean --onefile --windowed --name DayTasks --icon assets\icon.ico --add-data "assets\icon.ico;assets" --add-data "assets\icon.png;assets" --collect-all customtkinter daytasks.py
```

Готовый файл: `dist\DayTasks.exe`.
